# rec/ — video explicativo

Este directorio contiene el video asciinema de **Vending Solana: una máquina que cobra en USDC** y el reproductor
que se usa en la página del proyecto.

- `vending-solana.cast`: grabación original (asciicast v2).
- `vending-solana.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 2:58. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
